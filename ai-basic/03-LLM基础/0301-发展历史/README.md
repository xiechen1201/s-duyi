# 发展历史

LLM 和 AI 的关系？

LLM 属于 AI 中的一个分支。

AI 是一个宏大的领域，目标是让机器能完成人类派发的任务。LLM 是 AI 的一种具体的实现技术，通过深度的学习，能够理解自然语言。

```
AI（人工智能）
 └── 机器学习（Machine Learning）
      └── 深度学习（Deep Learning）
           └── 生成式 AI（Generative AI）
                └── 大语言模型（LLM）
```

深度学习？

受到「人脑神经的启发」。

模型是一个长期发展的过程，并不是最近才开始的，只是最近开始出圈。

Transformer 模型统治了深度学习领域。
