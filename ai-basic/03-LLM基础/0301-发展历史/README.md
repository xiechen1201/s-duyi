# 发展历史


## LLM 和 AI 的关系？

LLM 属于 AI 中的一个分支。

AI 是一个宏大的领域，目标是让机器能完成人类派发的任务。LLM 是 AI 的一种具体的实现技术，通过深度的学习，能够理解自然语言。

```
AI（人工智能）
 └── 机器学习（Machine Learning）
      └── 深度学习（Deep Learning）
           └── 生成式 AI（Generative AI）
                └── 大语言模型（LLM）
```

深度学习？

机器学习下面的一个分支，受到「人脑神经的启发」（不等于复制了整个人脑）。

通过多层神经网络来自动从数据中学习特征和模式。

模型是一个长期发展的过程，并不是最近才开始的，只是最近开始出圈。

Transformer （多模态语言模型）模型统治了深度学习领域。

## LLM 发展历史

AI 两大核心应用方向：

1、计算机视觉

2、自然语言处理（NLP）

早期的研究突破基本都设视觉相关的，自然语言属于后来者居上。

计算机不能理解人类的语言，缺少编码和解码的过程，因此要让计算机懂人类的语言，就需要对语言进行编码，转化为计算机能读懂的形式。

MLP 的核心任务就是让人类语言的进行某种形式的编码和解码，让计算机能够理解人类的语言，这样计算机才能处理人类的任务。

## NLP 的演进

1、起源

2、基于规则

人类尝试通过语法和语义跪着来解决 NLP 的问题（和人学习一门新语言的思路一致）。

问题：

- 一门语言的规则非常多，且十分复杂，基于无法基于语法规则进行建模；

- 语言是变化的艺术（不断的在发展，每年都会出现新的流行词）；

3、基于统计

1970 年，IBM 的科学家们采用了基于统计的方式来解决语音识别的问题，把一个基于规则的问题转化为一个数学问题，让 NLP 准确率有了质的提升；

一句话解释什么是语言模型？

一种捕捉自然语言词汇、短语和句子概率分布的「统计模型」。

这个时期，语言模型（统计模型）就已经出现了，不过还不能称为大语言模型，只能叫做语言模型。

4、深度学习和大数据驱动

深度学习和大数据时代为代表的新范式逐步取代了传统的统计模型。

大型预训练语言模型：大主要就是数据量大，把整个互联网的信息拿去训练，海量的书籍拿去学习，这就是大语言模型。
