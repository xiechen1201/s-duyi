# 组件渲染性能优化

```
<button
          onClick={() =>
            this.setState({
              // counter: this.state.counter + 1
              // 设置为 1 也会导致重渲染
              counter: 1
            })
          }>
          增加
        </button>
```

只要调用了 setState 就会导致重渲染（不管 counter 有没有变化）。

# memo

函数组件不存在 state 相同也会重渲染的问题，但是存在 props 相同触发重渲染的问题。

```
<ChildCom2 counter={counter2} />
```

ChildCom1 重渲染也会导致 ChildCom2 重渲染。

memo 是一个高阶组件，返回的新组件在 props 相同的情况下不会重渲染。

```
React.memo(ChildCom2);
```

默认依旧是浅层对比。

memo(Component, arePropsEqual?) 和 shouldComponentUpdate 返回的参数相反，返回 true 表示参数一致，不需要重渲染。

## useCallback

test 函数每次都重新生成，导致 props 都不一样，产生子组件重渲染。

useCallback 的作用就是缓存一个函数。

## useMemo

和 useCallback 很相似，主要用于缓存值。
