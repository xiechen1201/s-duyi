# React和Vue描述页面的区别

jsx vs Template

## JSX 的来源

起源于 React 团队中的一种类似于 XML 的语法糖。

jsx 语法会被进行编译，执行代码后，最终得到一个对象，这个对象就是虚拟 DOM。

可以轻松实现对复杂 UI 的描述，生态完善。

## Template 的来源

历史要从后端说起。

前后端未分离的时代，最流行的方案就是模版引擎，把服务端的数据填充到模版中。

基本上就是 vue 模版的雏型。

模版的出发点：既然前端是 HTML 来描述 UI，那么就拓展 HTML，让 HTML 可以描述一定的逻辑（从 UI 出发，拓展 UI）。

JSX 出发点刚好相反，前端使用 JS 描述逻辑，拓展 JS，JS 可以描述 UI（从逻辑出发，拓展逻辑）。

思路（方向）完全不一样，造成了框架架构的差异。
