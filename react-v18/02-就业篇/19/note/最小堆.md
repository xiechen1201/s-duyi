# 最小堆

在 Scheduler 中使用最小堆堆任务进行排序。

## 二叉树基本知识

### 二叉树

二叉树指的是一个父节点只能有一个或者两个子节点，总之就是不能多于两个。

### 完全树

完全树指的是填充一棵树在进行填写的时候，遵循的是从左到右，从上到下的顺序。

### 完全树中的数值

可以分为两个大类：

- 最大堆：父节点的数值大于或者等于所有的子节点；

- 最小堆：父节点的数值小于或者等于所有的子节点；

现象：

- 无论是最大堆还是最小堆，第一个节点一定是这个堆中数值最大的/最小的节点；

- 每一层并非是按照一定顺序来排列的；

- 每一层所有元素并非一定比下一层（非自己的子节点）大或者小；

### 堆的实现

一般来讲，可以使用数组来实现。

## React 中最小堆

最小堆对应的文件：packages/scheduler/src/SchedulerMinHeap.js，总共有 6 个方法，其中对外暴露了 3 个：

- push

- pop

- peek

没有暴露的是：

- shiftUp 向上调整

- shiftDown 向下调整

- compare 比较两个元素的数值大小

所谓向上调整，就是指一个元素和他的父元素做比较，如果比父节点小，则需要和父节点交换位置。继续和父节点做比较，直到和父节点的数值大小关系符合堆的性质。

### peek

取出堆顶的任务，堆顶一定是数值最小的任务。

### push

向最小堆推入一个新任务，因为使用的是数组，所以在推入任务的时候首先该任务是被推入数组的最后一项，但是这个时候涉及到一个调整，我们需要向上调整，把这个任务调整到合适的位置。

## pop

从任务堆里面弹出第一个任务，弹出后这个任务就不在队列中了。
