# 位运算

## 位运算的基础

二进制就是以二为底的一种计数方式。

逢 n 进 1 即为 n 进制。

基于二进制的位运算可以很方便的表达增、删、改。

### fiber 的 flgs

在 React 中用来标记 fiber 操作的 flags，使用的就是二进制。

之所以要抽离 fiber 的状态是因为这中状态，是因为这种操作是高效的。

针对一个 fiber 操作，可能有增删改，但是我不直接进行操作，而是对 fiber 打上一个 flag，接下来在后面的流程中，针对有 flag 的 fiber 统一进行操作。

通过位运算，可以很好的解决一个 fiber 有多个 flag 的问题，方便合并多个状态。
